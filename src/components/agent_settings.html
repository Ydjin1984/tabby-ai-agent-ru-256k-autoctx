Безопасность
Подтверждение команд
Ассистент может предлагать shell-команды с уровнем риска и пояснением. Эта опция пропускает подтверждение только для команд с риском low; команды среднего и высокого риска всё равно требуют ручного одобрения.
Как работает
Команды выполняются без подтверждения до выбранного уровня риска. Опасные команды (форматирование диска, рекурсивное удаление, реестр, firewall, shutdown) всегда требуют явного подтверждения, независимо от настройки.
Интернет
Веб-поиск и глубокий ресёрч
Агент ищет в интернете через DuckDuckGo без API-ключа. Быстрый режим возвращает заголовки, ссылки и описания; глубокий ресёрч сам разбивает вопрос на подзапросы, читает несколько источников и формирует досье. Режимы также переключаются кнопками Web и Deep в шапке панели.

Память агента
Накопление опыта
Агент запоминает, какие команды сработали в вашем окружении, и подставляет удачные решения перед следующими задачами. Память привязана к ОС, оболочке и runtime, поэтому решения для Windows/PowerShell не попадут в Linux/bash.

Дополнительные параметры запроса
Необязательный JSON, объединяемый с каждым стриминговым chat-completion запросом. Полезно для LiteLLM, llama.cpp, vLLM и других провайдеров с дополнительными настройками сэмплинга, размышления или шаблона.

Используйте строгий JSON с кавычками вокруг ключей. Оставьте пустым, чтобы отправлять только дефолты плагина. Частые ключи: temperature, top_p, top_k, thinking_budget_tokens и chat_template_kwargs.
